# Full-data local-path results

These tables summarize the production direct local-path analysis reported in `docs/differential.tex`. `summary.tsv` contains observed and design-matched null results after empirical calibration and BH correction. `runtime.tsv` reports aggregate one-core fitting time and peak worker memory from prepared analysis inputs. Structural annotations and literature follow-up for the primary omnibus discoveries are in `analyses/local_path_omnibus_event_annotation`; secondary pairwise localizations are in `analyses/local_path_full_event_annotation`.

Tealeaf uses two pseudo-observations per path, a label-independent pooled isoform baseline, a subject-blocked omnibus regression as the primary cell-type test, pairwise subject-level testing for localization, and independent subject-level multivariate regression for condition within cell type. Calibration uses \(R_{\rm null}\) design-matched Monte Carlo null replicates, with default \(R_{\rm null}=32\). Predictive empirical-Bayes smoothing and conditional Laplace covariance propagation are retained as appendix sensitivities because they did not improve subject-split replicated discovery.

Nested \(R_{\rm null}=64\) and 128 checks are recorded in `analyses/null_replicate_sensitivity`. Omnibus and full pairwise BH sets have Jaccard similarity above 0.988 with the nested 32-replicate results, and the condition family has no BH call at any budget.
