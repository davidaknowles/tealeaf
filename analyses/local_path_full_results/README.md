# Full-data local-path results

These tables summarize the production full-data testing-level empirical-Bayes analyses reported in `docs/differential.tex`. `summary.tsv` contains observed and design-matched null results after empirical calibration and BH correction. `runtime.tsv` reports the selected fit and complete eight-candidate selection-grid worker time, maximum selected-fit shard time, and peak worker memory from prepared analysis inputs. Structural annotations and literature follow-up for the omnibus discoveries are in `analyses/local_path_omnibus_event_annotation`; secondary pairwise localizations are in `analyses/local_path_full_event_annotation`.

The omnibus cell-type, pairwise cell-type, and condition-within-cell-type families each fit the fixed-total grid \(A\in\{2,4,8,16,32,64,128,256\}\) and independently select one global concentration with the gene-equal beta--uniform testing-level objective. All three select \(A=64\). The selected omnibus analysis calls 791 blocks from 572 genes, the secondary pairwise analysis calls 2,950 contrasts across 716 blocks and 531 genes, and the condition analysis has no BH discovery. Calibration uses \(R_{\rm null}=32\) design-matched Monte Carlo null replicates. Rerunning the complete selector inside every null family gives zero BH calls for all three analyses; selector-aware mean nominal-0.05 rejection is 0.05043, 0.05000, and 0.04995 for omnibus, pairwise, and condition.

The older fixed add-two \(R_{\rm null}=64\) and 128 checks remain in `analyses/null_replicate_sensitivity`; they do not substitute for rerunning the complete EB selector at those larger budgets.

For each family, `*_eb_evidence.tsv` records the complete observed-data evidence curve, `*_eb_selection.json` records the selected concentration and fitted mixture, and `*_eb_null_selection.tsv` records the concentration and rejection summary selected after rerunning the full procedure in each null family.
