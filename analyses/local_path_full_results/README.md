# Full-data local-path results

These tables summarize the earlier fixed add-two-per-path full-data analysis reported in `docs/differential.tex`. They do not contain the testing-level EB configuration used in the production comparator benchmark. `summary.tsv` contains observed and design-matched null results after empirical calibration and BH correction. `runtime.tsv` reports aggregate one-core fitting time and peak worker memory from prepared analysis inputs. Structural annotations and literature follow-up for the omnibus discoveries are in `analyses/local_path_omnibus_event_annotation`; secondary pairwise localizations are in `analyses/local_path_full_event_annotation`.

This archived run uses two pseudo-observations per path, a label-independent pooled isoform baseline, a subject-blocked omnibus regression as the primary cell-type test, pairwise subject-level testing for localization, and independent subject-level multivariate regression for condition within cell type. Calibration uses \(R_{\rm null}\) design-matched Monte Carlo null replicates, with default \(R_{\rm null}=32\). The current comparator method instead uses the testing-level EB selection of one global fixed-total concentration; count-predictive EB and conditional Laplace covariance propagation remain appendix sensitivities.

Nested \(R_{\rm null}=64\) and 128 checks are recorded in `analyses/null_replicate_sensitivity`. Omnibus and full pairwise BH sets have Jaccard similarity above 0.988 with the nested 32-replicate results, and the condition family has no BH call at any budget.
