# Full-data cell-type event annotation

`event_catalog.tsv` contains one row per BH-significant block-by-cell-type-pair test from the production direct local-path analysis. `event_type_summary.tsv` summarizes significant pairwise calls, while `event_type_block_summary.tsv` counts each of the 585 distinct blocks once. `literature_matches.tsv` records production blocks with previously audited primary functional evidence.

Terminal blocks are labeled alternative first or last regions because a supported path can differ at several exons or transcript ends. These labels do not by themselves distinguish promoter choice, terminal exon choice, or alternative polyadenylation.
