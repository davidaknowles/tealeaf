# Full-data cell-type event annotation

`event_catalog.tsv` contains one row per BH-significant block-by-cell-type-pair test after testing-level EB selected fixed-total concentration \(A=64\). `event_type_summary.tsv` summarizes 2,950 significant pairwise calls, while `event_type_block_summary.tsv` counts each of the 716 distinct blocks once. `literature_matches.tsv` records production blocks with previously audited primary functional evidence.

Terminal blocks are labeled alternative first or last regions because a supported path can differ at several exons or transcript ends. These labels do not by themselves distinguish promoter choice, terminal exon choice, or alternative polyadenylation.
