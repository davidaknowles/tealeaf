# SUPPA and rMATS comparator audit

This directory records the event-unit comparator additions to the subject-split and Tilgner long-read audits. `split_gene_metrics.tsv` and `split_topk_overlap.tsv` use the same shared gene-by-cell-type-pair Simes, two-fold conjunction, and BH procedure as the main benchmark. The Tilgner tables use full-data tests with all 48 short-read subjects per contrast, at most 500 ranked calls per contrast, and the common source-depth rules. `sign_agreement_by_rank.tsv` contains the top 200 evaluable calls for each event method. The split audit remains separate in `split_gene_metrics.tsv`.

The rMATS output uses JCEC counts and the native unpaired test. Paired rMATS statistics could not be executed because the installed package's R dependency requires an unavailable `libgfortran` ABI. The SUPPA executable was not installed, so `SUPPA transcript PSI` is a transparent implementation of transcript-derived PSI for the standard five event classes, with paired t tests and within-contrast BH. `suppa_event_catalog.tsv.gz` contains the event-to-transcript sets used for both PSI and the Tilgner mapping. These limitations are part of the comparison and are not hidden by calling the baselines native full-package results.
