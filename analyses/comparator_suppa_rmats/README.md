# SUPPA2 and rMATS comparator audit

This directory records the event-unit comparator additions to the subject-split and Tilgner long-read audits. `split_gene_metrics.tsv` and `split_topk_overlap.tsv` use the same shared gene-by-cell-type-pair Simes, two-fold conjunction, and BH procedure as the main benchmark. The Tilgner tables use full-data tests with all 48 short-read subjects per contrast, at most 500 ranked calls per contrast, and the common source-depth rules. `sign_agreement_by_rank.tsv` contains the top 200 evaluable calls for each event method. The split audit remains separate in `split_gene_metrics.tsv`.

The production SUPPA comparator is native SUPPA2 v2.4. `native_suppa2/event_catalog.tsv.gz` contains its standard five event classes, and `native_suppa2/full_tests.tsv.gz` contains transcript-TPM PSI tests using the native paired classical Wilcoxon procedure (evaluated in a vectorized equivalent). `native_suppa2/split_metrics.tsv` is the standalone two-half gene audit; the native event multiplicity yields no replicated split genes. `native_suppa2/full_tilgner_summary.tsv` records the independent long-read replication. The earlier `suppa_*` files are retained as a deprecated custom-PSI provenance audit and are not used for the current comparison.

The rMATS output uses JCEC counts and the native unpaired test. Paired rMATS statistics could not be executed because the installed package's bundled R/LAPACK dependency requires an unavailable `libgfortran` ABI. `rmats_native_diagnostics.tsv` records the sparse-count diagnostic: 99.997% of the 1,229,628 native event p-values are exactly one and no event survives BH. `native_suppa2/rmats_native_mapping.tsv` records the coordinate map used to audit rMATS event coverage. These limitations are part of the comparison and are reported explicitly rather than hidden by calling the baselines native full-package results.
