# SUPPA2 and rMATS comparator audit

This directory records the event-unit comparator additions to the subject-split and Tilgner long-read audits. `split_gene_metrics.tsv` and `split_topk_overlap.tsv` use the same shared gene-by-cell-type-pair Simes, two-fold conjunction, and BH procedure as the main benchmark. The Tilgner tables use full-data tests with all 48 short-read subjects per contrast, at most 500 ranked calls per contrast, and the common source-depth rules. `sign_agreement_by_rank.tsv` contains the top 200 evaluable calls for each event method. The split audit remains separate in `split_gene_metrics.tsv`.

The production SUPPA comparator is native SUPPA2 v2.4. `native_suppa2/event_catalog.tsv.gz` contains its standard five event classes, and `native_suppa2/full_tests.tsv.gz` contains transcript-TPM PSI tests using the paired classical Wilcoxon procedure, evaluated with a vectorized normal approximation to avoid the upstream event-by-event Python loop. `native_suppa2/split_metrics.tsv` is the standalone two-half gene audit; the native event multiplicity yields no replicated split genes. `native_suppa2/full_tilgner_summary.tsv` records the independent long-read replication. The earlier `suppa_*` files are retained as a deprecated custom-PSI provenance audit and are not used for the current comparison.

The paired rMATS rerun uses rMATS 4.1.2 with a clean R 4.3/PAIRADISE environment and JCEC counts. The pseudobulk BAMs are single-end-like, so the count pass uses single-end read handling; paired biological samples are still used by the PAIRADISE statistical model. The benchmark driver runs the JCEC paired model directly because the standard `--paired-stats` path redundantly fits both JC and JCEC while the comparison consumes JCEC. `rmats_native_diagnostics.tsv` records the earlier native unpaired sparse-count diagnostic. `native_suppa2/rmats_native_mapping.tsv` records the coordinate map used to audit rMATS event coverage.
