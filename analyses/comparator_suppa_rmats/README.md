# SUPPA2 and rMATS comparator audit

This directory records the event-unit comparator additions to the subject-split and Tilgner long-read audits. `split_gene_metrics.tsv` and `split_topk_overlap.tsv` use the same shared gene-by-cell-type-pair Simes, two-fold conjunction, and BH procedure as the main benchmark. The Tilgner tables use full-data tests with all 48 short-read subjects per contrast, at most 500 ranked calls per contrast, and the common source-depth rules. `sign_agreement_by_rank.tsv` contains the top 200 evaluable calls for each event method. The split audit remains separate in `split_gene_metrics.tsv`.

The production SUPPA comparator uses SUPPA2 v2.4 event definitions and PSI with the classical paired signed-rank test family. The matched split test now computes exact conditional tails, including tied absolute ranks. `suppa2/event_catalog.tsv.gz` contains the five event classes. `suppa2/split_data_matched_exact_fold0_tests.tsv.gz` and `suppa2/split_data_matched_exact_fold1_tests.tsv.gz` are the matched event tests used for Table 1. `suppa2/split_data_tealeaf_comparison_metrics.tsv`, `split_data_tealeaf_comparison_topk.tsv`, and `split_data_tealeaf_comparison_genes.tsv.gz` report the common Simes/conjunction/BH comparison against the merged, calibrated Tealeaf fit with selected total concentration 32. Every eligible event p-value enters aggregation; event-level BH is not a screening step. The exact test gives 21 replicated genes versus the previous approximation's one, on the same 2,342 gene--pair hypotheses and 457 genes. The complete eight-statistic sensitivity, matched event tables, gene p-values, support summary, event null rates, and complete null-family metrics are under `suppa2/statistics_audit/`. Paired-t alternatives give 10--18 replicated genes. None of eight statistics produces a replicated gene in 32 synchronized subject-sign null families.

The always-normal vectorized approximation was not equivalent to the upstream classical call to SciPy's Wilcoxon test. Its extreme tail was conservative at the available subject counts, and its tied-rank variance was missing the tie correction. Exact-tail recursion now uses normalized probabilities rather than int64 sign-assignment counts. The reusable implementation is `tealeaf.sc.event_tests`; all three SUPPA2 runners default to exact conditional signed-rank testing, with normal and paired-t sensitivities available explicitly. The archived `suppa2/full_data_tests.tsv.gz`, `split_data_fold0_tests.tsv.gz`, and `split_data_fold1_tests.tsv.gz` retain the earlier approximation. Their long-read rankings and unrestricted split audit are historical outputs, not silently relabeled exact-test results. `suppa2/full_data_tilgner_summary.tsv` records the independent long-read replication of that separate full-data ranking.

`suppa2_primer_aware/` reuses `tealeaf.sc.glm_cv.prepare_paired_primer_glm_data` and the production primer-specific EC probabilities, then converts expected EC allocations to the same SUPPA2 event catalogue. Production event PSI uses the theta abundance-fitting design. The shared event logit includes a primer offset estimated separately for full data and each subject fold, followed by the tie-corrected paired Wilcoxon normal approximation and BH correction. Events with fewer than eight valid subject pairs are excluded before BH. `full_data_tests.tsv.gz`, `split_data_fold0_tests.tsv.gz`, and `split_data_fold1_tests.tsv.gz` are split from one preparation pass; `event_catalog.tsv.gz` records the mapped events and fitted offsets. `split_data_tealeaf_comparison_metrics.tsv`, `split_data_tealeaf_comparison_topk.tsv`, and `split_data_tealeaf_comparison_genes.tsv.gz` are the matched comparison: event p-values are aggregated by Simes within gene--cell-type pair and scored on the gene--pair keys shared with Tealeaf in both folds. `full_data_summary.tsv` and `split_data_metrics.tsv` retain the unrestricted event audit as a separate sensitivity diagnostic. The raw EC-conditional event-allocation ablation is retained under `suppa2_primer_aware_raw/`.
The long-read rank audit is intentionally different from the split discovery benchmark: it ranks up to 500 nominally selected events per contrast and does not require BH, whereas the table aggregates all eligible raw event p-values by Simes and then applies a two-fold conjunction and gene-level BH. The historical primer-aware first fold has 23,986 nominal (p<0.05) tests and 533 (p<10^{-3}) tests among 331,526 tested events, but 32 event-level BH calls. Its median absolute effect is about 0.013, compared with 0.029 for transcript-TPM SUPPA2. The endpoints differ, but the normal signed-rank approximation also suppressed the extreme tail, so the former claim that the discrepancy was only an endpoint issue was too strong.
`full_data_tilgner.tsv.gz` and `full_data_tilgner_summary.tsv` give the independent long-read audit, with 1,782/3,873 pooled and 812/2,626 strict directional agreements. The method is also included in `analyses/tilgner_junction_replication/sign_agreement_by_rank.tsv`.

The paired rMATS rerun uses rMATS 4.1.2 with a clean R 4.3/PAIRADISE environment and JCEC counts. The pseudobulk BAMs are single-end-like, so the count pass uses single-end read handling; paired biological samples are still used by the PAIRADISE statistical model. The benchmark driver runs the JCEC paired model directly because the standard `--paired-stats` path redundantly fits both JC and JCEC while the comparison consumes JCEC. `rmats_paired_full_tests.tsv.gz` contains 5,864,730 event--contrast tests over 190 contrasts, with 1,497 within-contrast FDR calls. `rmats_paired_full_tilgner_summary.tsv` reranks the existing mapped event intersection using paired p-values. `rmats_unpaired_diagnostics.tsv` records the earlier unpaired sparse-count diagnostic. `rmats_unpaired_mapping.tsv` records the coordinate map used to audit rMATS event coverage.
