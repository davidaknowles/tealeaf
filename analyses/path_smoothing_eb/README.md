# Corrected empirical-Bayes path smoothing

This analysis corrects the cross-fitted empirical-Bayes sensitivity and evaluates both concentration scalings in the complete calibrated pairwise subject-split pipeline. The finite strength is global across block path dimensions. Five-way gene cross-fitting gives each held-out gene a strength selected without using that gene, so there are five training-derived global values per subject half rather than a separate value for every block dimension.

For a block with $S_b\in\mathbb N$ paths and pooled label-independent baseline $\bar{\boldsymbol\psi}_b\in\Delta^{S_b-1}$, the baseline-centered slab uses prior counts $\boldsymbol a_b=\alpha S_b\bar{\boldsymbol\psi}_b$ under `per_path` scaling or $\boldsymbol a_b=A\bar{\boldsymbol\psi}_b$ under `total` scaling. The finite grid is 0.5, 1, 2, 4, 8, 16, 32, 64, and 128. An exact point mass at zero path perturbation replaces the former approximation based on the largest finite concentration. For finite strength $h$ and point-null weight $w$, selection maximizes gene-equal held-out log evidence $\log\{w p(\boldsymbol c\mid\boldsymbol\delta=\boldsymbol0)+(1-w)p_h(\boldsymbol c)\}$, where $p_h$ is the Laplace-integrated slab likelihood. The slab normalization includes the $+\tfrac12\log S_b$ ILR-to-simplex Jacobian constant needed when pooling dimensions. The fitted $w$ is only a robust nuisance parameter for hyperparameter selection. Downstream testing uses the selected finite strength for every gene and never uses spike membership or posterior non-null probability.

`selected_strengths.tsv` records the corrected maps. Per-path scaling selects 4 or 8 pseudo-observations per path. Fixed-total scaling selects total concentrations 8, 16, or 32, with 16 selected in eight of ten cross-fitting strata. Point-null weights range from 0.917 to 0.973.

`summary.tsv` compares both EB fits with production uniform add-two smoothing. Both EB scalings remain calibrated and no fold-level null family makes a BH call. They are also nearly indistinguishable, per-path EB gives 97 and 31 fold-specific BH calls and fixed-total EB gives 98 and 30. Both produce 4, 0, and 0 independently replicated genes on the LeafCutter, MAJIQ Heterogen, and scQuint matched universes, compared with 50, 103, and 101 under production uniform add-two smoothing. EB also retains about 500 fewer eligible hypotheses per half and has lower fold-to-fold rank correlation.

The corrected result rejects concentration scaling as the explanation for the EB failure. The main mismatch is the baseline-centered predictive objective, which favors preserving the pooled path composition for the null majority and suppresses the deviations needed for differential-splicing discovery. Fixed-total concentration remains preferable on dimensional grounds, but this EB criterion is not used in production.
