# Reporting and ranking sensitivities

This audit keeps the production EB-selected statistical fits, p-values, BH discoveries, and split-benchmark testing effects unchanged. It compares short-read-only reporting estimates and ranking rules on the 704 existing LR-evaluable pairwise discoveries. The omnibus sensitivities select one strongest source-evaluable discovery pair per significant production block, then rank using the actual EB-selected omnibus table and its own analytic tail/statistic. Both full-data EB selectors select total concentration 64, separately from the split benchmark's 32.

`reporting_effects.tsv.gz` contains pooled local, primer-balanced pooled local, primer-specific, and unrestricted pooled isoform estimates at reporting concentration 1. Pooling aggregates each primer's EC counts separately by cell type; balancing rescales each nonempty primer total to the within-cell-type mean primer total. These alternatives change the reporting estimand from an equal-subject average toward a count-weighted estimate. Unrestricted isoform fits and local fits retain optimizer convergence checks. Missing, failed, or zero reporting directions fall back explicitly to the existing subject-mean reporting direction; they are not dropped from a ranked evaluation.

`rank_sensitivity_summary.tsv` reports top-40, top-100, and top-200 agreement and normalized discrete cumulative-agreement area. `rank_sensitivity.tsv.gz` preserves ranked rows for every assessed combination. The area at K is the mean agreement among the first 1, 2, ..., K calls, rather than ROC AUC. Short curves have unavailable K-specific metrics. `ranking_sensitivity.pdf` shows the production pairwise baseline and the continuous-tail/pooling ablations. `production_rank.tsv` contains only the original production reporting estimates and calibrated-first ranking, using the full production omnibus input rather than the formerly pre-truncated cache.

Pairwise A100 is 65.6% for production reporting/ranking, 73.0% for continuous analytic-tail ordering, 79.4% for pooled local reporting plus continuous ordering, and 80.0% for balanced pooled reporting plus continuous ordering. The latter two give 67% top-100 agreement, versus 58% for production reporting/ranking and 78% for SUPPA2 on its own eligible universe. Ranking by effect magnitude, effect times log evidence, or cross-primer concordance does not improve on 80.0%. No tested alternative matches SUPPA2's 90.7% A100.

These are exploratory choices evaluated using LR outcomes, not independent validation of an improved production model. Retaining split discovery performance follows from keeping its tests unchanged; it is not evidence that a new statistical test preserves calibration. Source counts use full fractional precision, with reconstruction checks against published LR effect norms and depths. Analysis executables are `audit_tealeaf_lr_effects.py`, `restore_tilgner_path_counts.py`, and `summarize_tealeaf_lr_ranking.py` in the repository's dataset-specific script directory; pooled reporting and rank-summary helpers are in the package.
