# Independent long-read replication

This analysis validates Tealeaf cell-type path effects against the published adult mouse-brain ScISOr-Seq2 data from Joglekar et al. (2024), generated by the Tilgner laboratory. It uses the processed annotated-transcript UMI matrix distributed with the authors' [analysis repository](https://github.com/noush-joglekar/biccn_tilgner_scisorseq) at source commit `f2e7efb285f6df0264ffcb3946553416e4f1986f`. The associated article is [Joglekar et al., Nature Neuroscience 2024](https://doi.org/10.1038/s41593-024-01616-4), and raw and read-level processed data are available through the [NeMO archive](https://data.nemoarchive.org/biccn/grant/rf1_tilgner/tilgner/transcriptome/scell/).

The validation targets the 2,950 BH-significant secondary Tealeaf pairwise cell-type tests selected with testing concentration $A_{\rm test}=64$. Reported Tealeaf path effects use the independent effect-size refit at $A_{\rm report}=1$. Eight Tealeaf cell types have a fixed correspondence to P56 long-read annotations. The two source animals per region define biological replicates. Mature oligodendrocytes include MFOL and MOL annotations; a sensitivity analysis including every oligodendrocyte stage changes the primary rates by less than 0.6 percentage points.

For each test, source annotated transcripts are matched to stable GENCODE transcript identifiers and collapsed through the same Tealeaf block-to-path map. A test is directionally replicated when the dot product between its Tealeaf and long-read path-proportion difference vectors is positive. The pooled endpoint requires at least 20 mapped long-read UMIs in each cell type. The stricter endpoint also requires at least 10 UMIs per cell type in each source replicate and agreement with Tealeaf in both replicates. Its sign-flip null is half the observed directional concordance between source replicates, rather than 25%, because source-replicate directions are correlated.

`pairwise_replication.tsv` records every selected test, mappings, effect agreement, depths, and source path counts. `replication_summary.tsv` gives depth and Tealeaf-effect sensitivities, and `mapping_sensitivity.tsv` records the oligodendrocyte and regional-neuron checks. `tilgner_column_mapping.tsv` audits source-column mapping. `long_read_replication.pdf` is the manuscript figure, and `manifest.json` records provenance and analysis choices. The source-specific executable workflow is `extra_scripts/assess_tilgner_long_read_replication.py`.
