# Eight-paired-mouse sensitivity

This directory repeats the depth-filtered Tealeaf EC-GLMM split reproducibility sensitivity with the same 100-UMI threshold and a stricter requirement of at least eight paired mice. It is a nested sensitivity for `../ec_glmm_split_reproducibility_min100_min4` and uses the same pairwise shared-universe construction. The primary full native-screened comparison is in `../ec_glmm_split_reproducibility_full_min4`.
