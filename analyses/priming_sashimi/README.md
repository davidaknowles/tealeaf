# Primer-separated sashimi plots

These plots provide direct read-level support for three high-confidence cell-type differential-splicing events from the production omnibus analysis. App block B3 is the exon-15 cassette, Gria2 block B1 is the flip/flop mutually exclusive pair, and Grin1 block B3 is the C1 cassette. For each block, the displayed cell-type pair has BH FDR below 0.05 and the largest `mean_difference_norm` among significant pairwise localizations. This norm is the Euclidean norm of the across-subject mean paired difference in local-path isometric log-ratio coordinates. The selected pairs and effect norms are cortical excitatory versus hippocampal pyramidal for App, 0.927, cerebellar granule versus cortical excitatory for Gria2, 0.455, and medium spiny versus midbrain inhibitory for Grin1, 0.088.

The workflow streams the 16 production spliced-pseudobulk BAM files. Those files retain unique genomic mappings and one alignment per cell barcode, UMI, locus, start, and CIGAR. Each alignment is assigned to poly(dT) or random-hexamer priming from its half-cell barcode. Coverage and junction arcs are pooled within cell type and primer, then divided by the number of primer-specific half-cells and multiplied by 1,000. Arc labels therefore report junction UMIs per 1,000 half-cells rather than raw read counts. Introns are compressed for display, and the bottom annotation contains only the local paths tested by Tealeaf.

The plotted intervals contain 2,210/5,122 cortical-excitatory and 186/478 hippocampal-pyramidal spliced UMIs for App under poly(dT)/random-hexamer priming. The corresponding values are 97/132 cerebellar-granule and 1,039/904 cortical-excitatory UMIs for Gria2, and 555/384 medium-spiny plus 148/330 midbrain-inhibitory UMIs for Grin1. Both priming strategies recover the tested structures, while their coverage and absolute support differ as expected from primer-specific positional exposure.

The sashimi tracks are descriptive checks rather than inputs to the statistical test. They omit unspliced and exonic-only EC observations and do not resolve ambiguous reads through the primer-specific EC maps. Production Tealeaf uses that larger observation set and all represented cell types in the omnibus test.

The grouped barplots report mean production fitted local-path proportions and standard errors across the paired subjects represented in each displayed contrast. The estimates jointly use both primer-specific likelihoods, so they are separated by cell type and path rather than by primer. Path numbering follows the tested-path GTF order. `path_usage.tsv` retains subject-level estimates and `path_usage_summary.tsv` retains the plotted summaries.

Two combined heatmaps per event extend the evidence display to every cell type represented in the production omnibus fit, with poly(dT) and random-hexamer priming shown separately. Columns are grouped by tested path, beginning with its across-subject mean fitted proportion and followed by its exon and junction components in 5'-to-3' RNA order. Minus-strand paths therefore run in descending genomic-coordinate order. Shared components are intentionally repeated under each path containing them and keep the same gene-wide E or J label wherever they recur; components outside the visualized block are excluded. Junction values are exact annotated-junction UMIs per 1,000 primer-specific half-cells, while exon values are mean aligned-base depth per 1,000 primer-specific half-cells. Coverage tiles use the raw normalized values on a common scale within each primer panel. Path proportions have different units, so neutral path tiles display fitted percentages rather than using the coverage color scale. Each event's `*_block_heatmap.tsv` retains raw values, coordinates, measurement types, and column order; `omnibus_path_usage.tsv` and `omnibus_path_usage_summary.tsv` retain the fitted inputs.

The selected-contrast, spliced-UMI support, cell-count, and fitted path-usage tables retain the audit data. Event subdirectories contain the ggsashimi inputs, tested-path GTF, block evidence matrix, and PDFs. The manifest records event identifiers, coordinates, all heatmap cell types, and figure paths. Reusable BAM summarization is in the package sashimi module; dataset-specific selection and plotting are in the microglia priming-sashimi script.
