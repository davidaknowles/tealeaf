# Local-path smoothing sensitivity

`summary.tsv` compares uniform path pseudocounts \(\alpha\in\{0,0.5,1,2\}\) on the two subject-split pairwise cell-type benchmark. Every setting is scored with the final robust variance moderation, leave-one-block-out empirical calibration, Simes aggregation, fold conjunction, and BH procedure. The \(\alpha=0\) fit predates the path-pseudocount metadata column, but its saved observed and sign-flip statistics were passed through the same final merger; its reduced eligible universe reflects boundary instability rather than additional filtering. The replicated-gene columns use the corresponding Tealeaf--comparator universe shared across both subject halves. The held-out replication rate is undefined for the \(\alpha=0\) scQuint comparison because neither fold has a Tealeaf discovery to evaluate.

The source fits and merged sensitivity outputs remain with the split benchmark run. The selected production setting is \(\alpha=2\). It maximizes independently replicated genes on each comparator-matched universe while retaining pooled null rejection near 0.05 and zero fold-level BH calls in all 64 null families. Because the setting was selected on these subject splits, it requires confirmation on independent data.
